# iOS 재심사 준비 — 2026-11-23

## 실제 기기에서 확인한 범위

TestFlight 1.56 (156.22.1)의 실제 iPhone에서 Apple 인증 후 이름·이메일 재입력 없이 가입 화면에 진입했고, 문자 수신·휴대폰 인증·사장님 신규가입·로그아웃 후 Apple 재로그인까지 완료했다. 기존 Apple 구매가 다른 매니 계정에 연결된 경우 재구매가 차단됐고 원래 매니 계정에서는 테스트 구독 인식과 복원 후 상태 유지가 확인됐다.

추가로 1.56 (156.24.1), iPhone 12 mini, iOS 16.4.1에서 새 TestFlight 초대 수락 후 신규 테스트 구매를 완료했다. Apple 구매 완료 화면, 매니의 테스트 구독 이용 중 표시, 매장 입력·수정 가능 안내를 확인했다. 실제 iPad 검증은 아직 완료되지 않았다.

## 반영한 내용

- iOS의 구독 거절 안내는 사장님에게 더보기의 구독 상태를 안내하고, 직원에게만 사장님 문의를 안내한다. 역할별 실행 테스트를 추가했다.
- 기존 심사 전용 가상매장 한 곳만 Sandbox 이용권 검증 환경으로 전환했다. 변경 전 Sandbox 매장은 0곳, 변경 후 1곳이다. 운영 결제는 계속 활성 상태이며 다른 매장은 Production 환경을 유지한다. 유효한 테스트 구매 없이 해당 심사 매장에 입력 권한을 부여하지 않았다.
- App Store Connect의 기존 심사 계정 비밀번호와 검증 안내를 갱신한 뒤 같은 API로 읽어 일치함을 확인했다. 실행 45091298125에서 updated, passwordVerified, notesVerified 모두 true였다. 비밀번호는 기존 Apple API 서명키의 공개키로 암호화한 자료만 저장소에 기록하고 실행 환경 안에서 복호화했다. 비밀키나 비밀번호는 로그에 출력하지 않는다.
- 심사 빌드 선택, 정식 심사 제출 또는 계정의 구매 소유권 이전은 수행하지 않았다. 확인한 앱 버전 상태는 REJECTED다.

## 아직 필요한 사항

1. 신규 구매 → 올바른 매니 계정의 서버 저장 → 심사 전용 매장 입력 권한 반영과 정상 사용자 API의 매출 저장·재조회·정리를 확인했다. 사용자가 앱 완전 종료·재실행과 이번 새 구독 복원을 확인했고 이후 구독 화면도 정상 유지됐다. 실제 아이폰의 매출 입력 폼·저장 버튼과 손가락으로 팝업 배경 스크롤을 막는 동작은 별도 확인이 남았다. 이전에 확인한 다른 Apple 계정의 기존 구독 복원과 이번 신규 구매 복원을 혼동하지 않는다.
2. 심사자가 첫 Apple 가입을 직접 검수하려면 한국 번호의 SMS 인증 코드를 받을 수 있는 절차가 필요하다. 일반 사용자의 휴대폰 인증을 완화하거나 클라이언트에 고정 인증번호를 넣지 않았다. 유효기간이 짧은 실제 SMS 코드를 미리 심사 노트에 적는 것으로 해결됐다고 간주하지 않는다. 이번 구매로 데모 계정의 구독은 활성 상태가 됐으므로 만료 구독 심사용 상태도 다시 준비해야 한다. 신규가입 SMS는 App Review 통화 등 전달 일정과 연락 절차를 정해야 한다. 통화 예약은 아직 하지 않았다.
3. 실제 iPad의 신규 구매 및 심사자의 인증 절차가 준비되기 전에는 재제출 준비 완료로 보고하지 않는다.

## 일반 로그인 API의 실제 저장 검증 — 2026-11-23

사용자의 검증 진행 요청에 따라 기존 사장님 로그인 엔드포인트에 데모 계정으로 정상 로그인했다. 반환된 사용자 ID가 사전 확인한 데모 계정과 일치함을 확인하고, 그 새 세션의 사용자 토큰과 publishable key로만 PostgREST를 호출했다. service role이나 SQL INSERT로 저장하지 않았다.

주 심사 전용 가상매장의 2026-11-23 매출이 없는 것을 먼저 확인한 뒤 총매출 1,000원·카드매출 1,000원인 검증용 레코드 한 건을 만들었다. API 응답은 201이었고 생성 후 같은 계정으로 다시 읽어 금액과 고유 검증 메모를 확인했다. 해당 ID·매장·검증 메모가 일치하는 레코드만 같은 사용자 API로 삭제하고 다시 조회해 남아 있지 않음을 확인했다. 이번 검증용 세션만 local scope로 로그아웃했다. 사용자의 아이폰 세션은 로그아웃하지 않았다.

결과: normalOwnerLogin=true, privilegedWriteUsed=false, insertVerified=true, readVerified=true, cleanupVerified=true, testSessionLogoutVerified=true.

이로써 실제 신규 구매 후 서버의 정상 사용자 저장 경로까지 확인했다. 아이폰 매출 폼의 입력·저장 버튼 조작을 대신하지는 않는다. 해당 화면의 실제 저장 조작, 실제 iPad 확인, 신규가입 SMS 심사 전달 절차는 별개로 남아 있다. 이전 절의 신규 저장 미확인은 이 API 검증으로 서버 범위에서 해소됐으며 테스트 레코드는 정리되어 최종 데이터에는 남지 않는다.

## 심사 노트 정정 및 통화 요청 준비 — 2026-11-23

App Store Connect에서 정식 버전 1.56은 Rejected, 선택 빌드는 156.21.1인 것을 다시 확인했다. 외부 TestFlight 156.24.1 베타 검토는 Waiting for Review였다. 두 심사를 혼동하지 않는다.

Apple의 11월 21일 메시지를 직접 읽어 만료 구독 데모 계정 및 인증 코드 전달을 위한 App Review 통화 요청이 실제 요구 사항임을 확인했다. 메시지는 심사 기기를 iPad Air 11-inch (M3)로 명시했다. 첨부 화면의 필드는 매니 신규가입 SMS이며, Apple이 요청한 코드가 이 필드의 코드인지 확인하는 문구를 통화 요청서에 포함했다.

정식 심사 Notes와 베타 Review Notes를 현재 결과로 교체하고 페이지 재로드 후 저장된 내용의 일치를 확인했다. 핵심 정정은 todtod07의 현재 Sandbox 구독 활성 상태, 신규 구매 실기기 통과, 사용자 확인에 근거한 재실행·복원, 정상 사용자 API 저장 검증, 아이폰 폼·실제 iPad 미검증이다. 기존의 '신규 구매 미검증' 및 '데모 구독 없음' 문구는 현재 안내에서 제거했다. 계정 자격 증명, 연락처, 정식 선택 빌드, 출시 방식은 변경하지 않았다.

기존 App Review 답변은 위 사실과 SMS 통화 조율 요청을 담은 초안으로 수정하고 Save Draft 완료를 확인했다. Reply 전송은 하지 않았다.

Apple 메시지가 제공한 공식 통화 요청 폼을 열어 앱·팀·현재 사용자 연결을 확인했다. 국가 코드 82, 2.1 Information Needed, 한국어 지원 및 실제 SMS 코드 전달 조율 사유를 준비했다. 시간대 옵션은 Japan time(UTC+9)이며 한국 시간과 같은 오프셋이다. 전화번호는 미입력이고 Submit은 누르지 않았다. 통화를 받을 번호와 담당자 수신 가능 여부를 확인한 후 접수할 수 있다. 아직 예약이나 접수 완료로 보고하지 않는다.

기존 iOS simulator build 워크플로는 generic iOS Simulator 컴파일이며 실제 iPad 구매·입력 조작 검증이 아니다. 기존 WebKit 820px 검증도 실제 iPad 검증으로 대체하지 않았다. 동일 소스의 모바일 테스트를 불필요하게 반복 실행하거나 새 바이너리를 만들지 않았다.

주의: review-ops/review-details.enc.json 및 ios-beta-review-info.yml의 이전 실행 입력은 당시 상태의 역사적 자료다. 이를 그대로 재실행하면 구식 검증 안내가 다시 적용될 수 있으므로 최종 심사 준비 시 현재 Notes를 기준으로 새 입력을 준비해야 한다.


## Apple 심사 통화 요청 접수 완료 — 2026-11-23

사용자가 가입 시 문자 인증이라고 설명해 통화를 요청하라고 명시적으로 승인했다. 공식 Apple Developer App Review call 폼에서 기존 로그인 사용자·법인·매니 앱 연결을 유지하고, 승인된 끝자리 4312 연락처를 국가 코드 82와 함께 입력했다. 사유는 매니의 신규 Apple 가입에 필요한 한국 휴대폰 SMS 인증 및 심사자의 인증 시도·코드 전달 조율이며 한국어와 한국 업무시간(UTC+9)을 요청했다. 비밀번호·실제 OTP·테스트 세션 토큰은 제출하지 않았다.
