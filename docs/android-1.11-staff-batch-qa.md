# Android 1.11 직원 기능 일괄 검증

사용자는 기능별 화면 요청을 반복하는 방식이 오래 걸린다고 지적했다. 직원 등록·근태·스케줄·급여·보고서 및 권한을 묶어 검증하고, 이미 실제 기기에서 확인한 예약·알림·파일 열기는 반복 요청하지 않는다.

## 수정

- 직원 추가 버튼의 진행 중 중복 요청을 차단하고 등록 중 상태를 표시한다.
- 저장 중 계정·매장·화면 문맥이 바뀌면 늦게 도착한 응답이 새 직원 목록이나 입력 내용을 덮어쓰지 않는다.
- 급여의 음수·소수·숫자 뒤 문자·DB 정수 범위 초과 입력을 거부한다. 관리 권한 및 저장 응답 ID도 확인한다.
- 저장 실패나 결과 미확인 시 입력 내용을 유지한다. 성공 후 재무 요약 캐시를 무효화한다.

## 검증 결과

수정 전 직원 추가의 중복·문맥 전환·잘못된 금액 문제를 재현했고 수정 후 회귀검사로 확인했다. 24개 테스트 파일의 Node/PGlite 검사 315개 통과, 실패·건너뜀 없음. 대상은 직원 정보 변경, 등록·승인·계정 연결, 권한 분리, 근태 저장과 실패 복구, 스케줄, 근무별 30분 미만 절사, 자정 통과, 세후급여, 가불 이중 차감 방지, 무급휴무, 재무 합계, 보고서 보존·출력, 지출·매출 저장이다.

테스트는 로컬 가상 상태 및 합성 DB를 사용했다. 실제 휴대폰 위치 권한·GPS 출퇴근, 여러 실기기의 동시 처리 및 장시간 토큰 갱신을 이번 검사로 확인했다고 주장하지 않는다. 예약 등록·도착·취소 푸시와 PDF·엑셀 열기는 이전 사용자 기기 검증을 유지한다. 사용자 매장 데이터와 운영 서버는 변경하지 않았다.

빌드 및 APK 검증 통과. versionCode 12 / 1.11-android-test, 기존 서명 인증서와 동일하며 수정된 직원 등록 코드가 APK에 포함됐다. GitHub 게시는 이전 승인 제한에 따라 실행하지 않았다.
